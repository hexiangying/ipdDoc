# 1、调试HTTP接口

如果要调试HTTP接口，必须先设置调试环境。前往【模块配置】-> 【调试环境】

<img src="/apidoc/static/help/images/debug1.png" style="height: 300px" />

点击`新增环境`，输入环境名称以及调试路径，到端口号即可

<img src="/apidoc/static/help/images/debug3.png" style="height: 300px" />

切换到【浏览模式】预览文档，在调试页面会出现刚才配置的调试环境

<img src="/apidoc/static/help/images/debug4.png" style="height: 200px" />

此外还可以添加测试环境等其它环境，方便在不同环境中进行调试。

# 2、调试DUBBO接口
目前系统已经内置钢联和隆众测试ZK作为DUBBO调试环境
<img src="/apidoc/static/help/images/debug5.png" style="height: 300px" />
如果用户想调试本地环境，可以输入本地ip:port直接调试（注意此处使用 192开头地址，切勿使用localhost或者127.0.0.1）
<img src="/apidoc/static/help/images/debug6.png" style="height: 300px" />
